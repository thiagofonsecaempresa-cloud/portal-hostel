Backup e portabilidade

Seus dados são seus. Faça cópias e leve-os para outro navegador.

Importante: Os dados ficam salvos na nuvem do portal e aparecem em qualquer aparelho. Use a exportação para fazer backup.

⇩ Exportar todos os dados

Baixe um arquivo JSON com reservas e configurações dos quartos. Guarde-o em local seguro.

⇧ Importar backup

Restaure um arquivo JSON exportado anteriormente. A importação substitui os dados atuais deste navegador.

▦ Exportar tabela CSV

Exporta as reservas para Excel, Google Planilhas ou outros programas de planilha.

⚠ Limpar todos os dados

Apaga os dados do Hostel na nuvem, para todos os usuários. Exporte um backup antes de continuar.

Configurar quartos

O hostel tem cinco quartos, numerados de 5 a 9. Ajuste o nome e a capacidade de cada um. A configuração de camas é apenas informativa.
